# elt-web

React light client for the EDGAR Form 4 lake — same scope as [elt-ios](https://github.com/MarkInNVA/elt-ios): Companies and People tabs, trade drill-down, fixed lake knobs.

**Stack:** Vite, React 19, TypeScript, MUI, TanStack Query, React Router.

**Docs:** [docs/startup.md](docs/startup.md)

**Platform / editions / ingest:** [elt-ios docs/platform.md](https://github.com/MarkInNVA/elt-ios/blob/main/docs/platform.md)

```bash
npm install
cp .env.example .env
npm run dev
```
